# AmPhi-Labs-Hackhaton-October-2026

**Context**Only about 10% of flexible plastic packaging is recycled today, because multilayer tubes and dirty foils are cheap and easy to run on packing lines. For the AmPhi Labs "Pack for 2030" hackathon, we set out to help brand owners recycle more for the same price by showing them realistic alternative materials and packaging.

**Together with the Giada group, we took first place out of four teams as the most tangible and creative idea!**

**Pack Swap Advisor app** is a Streamlit-based application that takes a product, its destination market and what matters most to the brand, then ranks more recyclable alternatives with a yearly cost-benefit and CO2 impact, plus an AI explanation by Claude (on illustrative data).

I built it with the Claude Code from a single `requirements.md` as the source of truth: one question at a time, every answer was recorded as a numbered question (Q-xx) or decision (D-xx) only after approval, and each build step was checked with a `/dod` command against the acceptance criteria.
